# Proyecto Machine Learning

## Predicción del BrentEquivalentProductionCost en activos Upstream de Oil & Gas

**Estudiante:** Leonella Torreglosa Portillo

**Asignatura:** Machine Learning

**Entregable 1 y 2**

Este Jupyter Book documenta el desarrollo del proyecto de Machine Learning para la predicción del BrentEquivalentProductionCost utilizando información de activos upstream de petróleo.

## Componentes del proyecto

- Selección y preparación de la base de datos.
- Análisis Exploratorio de Datos (EDA).
- Auditoría de Data Leakage.
- Modelo base SVR Lineal.
- Dashboard Dash Plotly desplegado.
